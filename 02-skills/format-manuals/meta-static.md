# Meta Static — format manual

The format manual for in-house Meta statics across all 5 markets and 3 funnel stages.

KPI is CPTD. Brand canon is the floor, not the ceiling. The job is creative that lands the parent's specific moment and pulls them into the funnel — coherently, ad → LP → trial.

---

## When to invoke

You are writing a Meta static when ALL of these are true:
- Surface = Meta feed / Stories / Reels-static-frame / Carousel-frame
- Format = single image (4:5, 1:1, 9:16, or 4:1 banner) or carousel-card-set
- Audience = parent in a Cuemath target cell (NRI / East Asian / UK Asian-origin / Indian-Australian / MEA expat)
- Funnel stage = TOFU (cold, build awareness) · MOFU (warmed, consider) · BOFU (intent-hot, convert)

If you're writing a video script, an LP fold, an RSA, or an influencer post — wrong manual.

---

## Physics of this surface

| Property | Reality |
|---|---|
| Read context | Parent scrolling Meta feed mid-day or evening. Passive attention. Not in research mode. |
| Time budget | **3-second hold decides everything.** If the hook fails, the rest doesn't matter. |
| Trust state | Cold (TOFU) → warm (MOFU) → intent-hot (BOFU). Hook physics change per stage. |
| Eye path | Hero image first, ad headline second, sub last. Close card lives in image's bottom strip. |
| Platform constraints | Ad headline: 40 chars Meta-displayed. Primary text: 125 chars before truncation. Image-overlay text: <20% of frame per Meta rules. |
| Spec sheet | 4:5 (1080×1350) feed · 1:1 (1080×1080) feed · 9:16 (1080×1920) Stories/Reels · 4:1 banner if Demand Gen-style |

## The four copy slots — distinct jobs, different copy

This is where most drift happens. Each slot has a different job. Same copy across slots = wasted ad.

| Slot | Job | Example |
|---|---|---|
| **Image headline** (on the visual) | OUTCOME — what the child gains, parent's situation made specific to maths | *"B− isn't a math problem. It's a thinking problem."* |
| **Ad headline** (Meta-rendered, 40 char) | PAIN — the worry that lives in the parent's head | *"She got the answer. Can she explain why?"* |
| **Subline / primary text** | MECHANISM — what Cuemath does, in mentor voice, single USP | *"We don't fix grades by drilling more problems. We teach your child to explain her steps before she solves."* |
| **Close card / fletch** (bottom strip of image) | BRAND ATOM — the philosophy that lands after the click is earned | *"Same Cuemath Coach. Every Single Class. Making Your Child MathFit™."* (locked, verbatim) |

**Image headline ≠ Ad headline.** Most mistakes I see have the same line twice. If they're identical, you've written one slot and copy-pasted it.

## Lock / Free / Anchor per funnel stage

### TOFU (cold, build awareness)

**Locked:**
- Close card verbatim
- CTA = "Book a free 1:1 class"
- Single MathFit dimension (or none) — never two
- Coach visible via tenure or memory (not bare-name)
- 3-beat shape (pain → mechanism → close)

**Free:**
- Image headline (outcome)
- Ad headline (pain — different copy)
- Subline (mechanism, single USP)
- Italicised felt word
- Which observed moment / kid behavior

**Anchor (read these before drafting):**
- Trustpilot CSV slice for this market + grade band (parent voice mining)
- Godfather creative_tags_v3 — current TOFU winners in this cell, their tag profile
- CD v1 §8 reference templates for the parent goal
- DBS §8 dynamics table (10 parent-child moments) — pick one, don't invent

### MOFU (warmed, consider)

**Locked:** All TOFU locks. Plus: comparison framing is one-sided (we differ on X), never names competitors.

**Free:**
- Carousel format if needed (5 slides max)
- Side-by-side comparison structure
- Proof-stacking (Trustpilot quote + outcome + tenure)

**Anchor:**
- Cell-weighted CPTD benchmark in Godfather
- Comparison taxonomy per market (see "Competitor framing" below)
- The exact RSA/LP this static is retargeting from — message-match the upstream surface

### BOFU (intent-hot, convert)

**Locked:** All TOFU locks. Plus: no offers, no urgency, no discounts in close.

**Free:**
- Direct-CTA framing
- Before/after evidence (number-led)
- Specific outcome (named child, named placement, named score)

**Anchor:**
- Retargeting audience cell (who saw what)
- Most recent verified outcome from this cell (Trustpilot or Godfather)
- The trial promise (what the next step is exactly)

## Variation axes — combinatorial, never surface

When you ship N variants, differentiate at architecture level. Lock the 5 brand-mandatory anchors above. Permute across at least 4 of these axes:

1. **Voice / POV** — observed-mother · kid-as-speaker · mentor-observation · method-as-agent · time-as-protagonist · artifact-as-subject · direct-address · statistical-observation
2. **Opening hook type** — pain · behavioral moment · artifact (report card, score, worksheet) · question · number · silence
3. **Frame structure** — single hero frame · 3-beat sequence (Reels-static) · split-screen comparison · before/after diptych · proof-card layout
4. **Evidence pillar** — outcome (number) · tenure · memory · Trustpilot quote · observed kid behavior · parent reversal
5. **Ending shape** — locked close card (always) — but where it sits, how it transitions, what carries to it

**If two variants share 3 of these 5 axes, that's pattern lock. Redraft.**

Read all variants aloud back-to-back before sending. Four versions of one piece = templating failed.

| Lead | Mix by campaign (no global default) |
| Sales angle | Value justification — pedigree + pedagogy. NOT personalization (off-brand for India). |
| Visual styles allowed | Product/platform interface · outcomes (named kid + cert/score/award) · real Indian kids studying. **NOT parent-kitchen-moment.** |
| Triggers all active | Memorisation gap · falling behind · achievement aspiration · better-than-local |
| Seasonal | Apr-Jun (new academic year) · Aug-Nov (mid-cycle) · Sep-Dec (Olympiad). NOT Jan-Mar (K-8 means boards out of scope). |
| Channels | Meta · Google · WhatsApp · LinkedIn (premium audience). NOT YouTube. |
| Currency | ₹ — only in INDIA creative. "4 Lakh+" not "400,000+". |
| Competitors | BYJU'S / Vedantu / PW (edtech apps) + Aakash / FIITJEE / Allen (coaching centres). NOT local 1:1 tutors. |
| Maths anxiety | REAL in India — acknowledge it (unlike US where kids are ahead) |
| "Fun / gamified" | Supporting claim OK — never lead |

## CPTD gates — what to ship-test against

Before drafting any variant:

1. **Cell-weighted CPTD benchmark** — pull from Godfather. What's the amber threshold for this market + grade band + audience cell?
2. **Current winners' tag profile** — query creative_tags_v3 for this cell. What tags map to low CPTD?
3. **Hook type to A/B against** — if H1 (pain) is currently winning, test H2 (evidence) or H3 (human-tutor). Don't ship a fifth variant of an already-winning pattern.
4. **Volume floor** — for verdict ≥ Working: TDs ≥ 3 + green CPTD + green CPTQL · OR · age ≥ 14d + amber + volume floor met.

If you don't know the benchmarks before writing, you're writing blind. Open Godfather first.

## Failure modes — the recurring ones

Read before drafting. If you find yourself reaching for one of these, stop.

1. **Parent-narrating-one-kid voice lock.** "She did X / he did Y." Every static defaults here. Vary the voice consciously.
2. **MathFit compound noun invention.** Only Application / Clarity / Confidence. Banned: MathFit Minds, MathFit thinking, MathFit Pedagogy, etc.
3. **Philosophy-as-opener.** Brand atoms ("Tricks fade. Understanding compounds.") are CLOSES, not OPENS. Same for "If she can explain why, she'll never forget how."
4. **Copywriter clichés.** "The tutor your child will keep." "Picked from the top 1%." "Builds a plan." Any line that reads like ad-headline rhythm, not parent speech.
5. **Bare-name coach in performance copy.** "Coach Karthik delivered." Never. Use "Cuemath coach" + tenure or memory.
6. **Made-up testimonials.** No invented parent signatures. No Kiran or Rohini (parents objected). All Trustpilot quotes must be verifiable.
7. **Multi-USP cards.** Two USPs in one static = two assets, not one.
8. **Hallmark sentimentality.** "Every dinner, every word problem, every bit of patience." Strip to specific concrete moments.
9. **Same line in image headline + ad headline.** Different jobs, different copy.
10. **Soft negative comparisons.** "School doesn't offer..." / "Coaching centres fail..." — borderline tutor/school-bashing. Brand book bans.
11. **NAPLAN / 11+ / AMC out of season.** Seasonally-indexed. Don't run NAPLAN creative in May. Don't run 11+ in March.
12. **Cross-market language borrowing.** Don't put ₹ on AU. Don't put "Year 5" on US. Don't put "monthly plan" anywhere.
13. **Framework names in parent VO / on-screen text.** FUAR / Clarity-Application-Confidence dimensions live in brand text only, never quoted as parent speech.
14. **Confidence-stated audits ungrounded in dates.** Verify the seasonal window before writing time-bound copy.

## Coherence checks (mandatory before ship)

This static doesn't exist alone. Fill in before drafting:

```
Campaign: [campaign-id — e.g. UK-11plus-Y5Y6-prep]
Static funnel stage: [TOFU / MOFU / BOFU]
Audience cell: [market + sub-ICP + grade band]

What surface brought the parent here (upstream)?
- If this is a retargeting static, what RSA / Demand Gen / LP did they see first?
- The promise this static reinforces:

What surface does this lead to (downstream)?
- LP it links to: [URL or LP-ID]
- Does LP fold-1 mirror this static's promise within 5 seconds of scroll? [Y/N]
- Does the email-1 in the nurture sequence echo the same vocabulary?

Vocabulary lock for this campaign (the words that must stay consistent across surfaces):
- 

Proof anchor referenced (same one across all surfaces):
- 

CTA across surfaces:
- This static: "Book a free 1:1 class"
- LP: matches
- Email: matches
```

If the LP doesn't reinforce this static within 5 seconds, the LP needs to change OR this static needs to change. Coherence is the gear that converts brand discipline into CPTD reduction.

## Output checklist before ship

CD v1 §10 + format-specific. Every Meta static must answer YES:

- [ ] Goal named (one of: grades / acceleration / depth / competition / SAT/exam)
- [ ] Single MathFit dimension named (or NONE — never two)
- [ ] Mechanism line in parent's language (one sentence, single USP)
- [ ] Coach visible by tenure or memory (NOT bare-name as outcome source)
- [ ] CTA = "Book a free 1:1 class" (or HS-only diagnostic CTA per §5)
- [ ] Close card locked verbatim — *"Same Cuemath Coach. Every Single Class. Making Your Child MathFit™."*
- [ ] Image headline ≠ Ad headline (different copy, different jobs)
- [ ] Bleached-language scrub — no "world-class · best · leading · proven · #1 · industry-leading · premier"
- [ ] Hard-ban scrub — no "specialist · teacher · classroom · centre · children · math is easy"
- [ ] Per-market overrides applied (currency, language register, visual style, exam-prep validity, banned visuals)
- [ ] Coherence block filled (campaign-id, upstream, downstream, vocabulary lock)
- [ ] CPTD benchmark checked — does this ship-test beat or match current winner in this cell?
- [ ] Variation axis check (if part of a variant set, ≥4 axes differ across variants)
- [ ] Read-aloud test passed (sounds like a real person observing, not a deck)
- [ ] Sister test passed (would a mum text this to her sister tomorrow?)

If any box is unchecked, the asset doesn't ship.
