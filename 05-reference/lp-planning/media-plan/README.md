# Media Plan & Channel Allocation

**Source:** https://docs.google.com/spreadsheets/d/1q_mScP2PfbP-cCMzcLyq1YyDkaNes2rFV4GvmWFc15g/

This is **separate from the calendar/narratives**. The calendar tells you *when* and *what to say.* The media plan tells you *where the money is, what's BAU, and what new platforms are being tested.*

Radar and the LP writer both read this — different jobs:

- **Radar** uses it to know which channels are active for each market (so Context Cards can route to the right channel).
- **LP writer** uses it to set voice — brand-awareness LPs sound different from performance LPs, and an LP for LinkedIn is different from one for TikTok.

---

## What lives here

| File | What it is |
|---|---|
| `channel-mix-summary.md` | Digest of what's BAU vs experimental per market, brand vs performance budgets, new channels in test. **Read this first.** |
| (Sheet itself) | Stays in Drive. Re-read or re-export when budgets shift. |

---

## Update rhythm

The Sheet is a live operational doc — budgets change frequently. Re-read it whenever Radar / Writer is asked about a market and you suspect the channel mix has shifted. **Don't cache stale numbers.**

When channel mix changes meaningfully (e.g., a new platform graduates from experiment to BAU), update `channel-mix-summary.md` so the writer doesn't have to re-parse the Sheet every run.
