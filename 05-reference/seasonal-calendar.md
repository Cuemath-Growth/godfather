# Seasonal Calendar — By Geography

This calendar drives contextual awareness for all agents. Sentinel uses it to explain performance spikes/dips. Lens uses it to tag seasonal creatives. Forge uses it to anchor copy in timely moments. Oracle uses it to recommend upcoming content windows.

**Forge fact-check rule (May 6, 2026):** before producing any copy with a time-bound claim, a numeric outcome, a contest/exam name, or a seasonal reference — consult this calendar. Verify the timing math against today's date. **If the claim cannot be sourced from a verified row in this doc (or another canonical source — CMS, brand doc), reject the copy.** Past Cuemath ad names are not a valid source — they may be context-shifted (e.g., "30-day prep" = program length, not a countdown).

---

## How to Use This Calendar

- **Forge:** When generating copy, check if a seasonal moment is within 2–4 weeks. If yes, offer a seasonal angle alongside the evergreen angle. **Before any time-bound headline, verify event date against the "Verified exact dates" table below.**
- **Lens:** Tag any creative that references a seasonal event with the relevant `hook` value (e.g., Fear/Urgency for deadline-driven events, Offer/Price for seasonal promotions) and note the specific event in the creative's context.
- **Oracle:** Flag upcoming windows in the pipeline status: "NAPLAN prep window opens in 3 weeks — no AU creatives in rotation."

### How to read "verify"

- **(passed)** — date already gone for current year. If a creative is referencing this event, it must be for the next year — check the next column.
- **(verify [authority])** — date is approximate; confirm against the named authority before launch. Don't ship a date claim with a "verify" tag still attached.
- **No tag** — date is fixed by Gregorian calendar rule (e.g., 2nd Sunday of May) or government statute. High confidence.

### What this catches

- "30 days to Math Kangaroo" written in May → fails (Math Kangaroo 2027 is Mar 18 = 316 days away)
- "Mother's Day creative" shipping in June → fails (Mother's Day passed)
- "AMC 8 prep" launching in February → fails (AMC 8 2026 already over; next is Jan 2027)
- "Diwali sale ends Saturday" with date that doesn't match Hindu calendar → fails

### What this does NOT catch (still requires human/Acads verification)

- Specific student outcomes ("Aarav scored 720 on SAT") — must cross-check CMS / Trustpilot / coach record before claiming.
- Statistical claims ("85% Y1 retention," "1-in-200 hire rate") — verify with current ops data.
- Curriculum coverage claims ("covers 2 years ahead of Common Core") — Acads/Joyita sign-off required.

## ROW Calendar

> Stub — Rest of World covers Singapore, Canada, Ireland, NZ, broader EU and SEA. School calendars vary too widely for one table; treat each sub-market case-by-case.

### Principles for ROW
- **Default to the sub-market's school calendar.** Don't blend Singapore (term system, PSLE in Sep–Oct) with Canada (Sep–Jun + summer Jul–Aug) with NZ (4-term, mirrors AUS roughly).
- **Identify the sub-market in every Context Card.** ROW alone is too vague for an LP brief.
- **Cultural calendar varies.** Diaspora moments (Diwali, Lunar New Year) cross-cut. Use the relevant US/India/AUS row as a starting reference, then localise.
- **Use English-language anchors.** No vernac unless we know the sub-market's language preference.

### Sub-markets to track (when spend justifies)
- Singapore: Term system, PSLE Sep–Oct, A-Levels Nov, Lunar New Year Jan–Feb
- Canada: Sep–Jun school year, summer break Jul–Aug, Diwali for NRI segment
- Ireland: Similar to UK; Junior/Leaving Cert May–Jun
- NZ: 4-term system roughly mirroring AUS

> When ROW spend grows in a single sub-market, promote it to its own section in this file.

## Calendar Maintenance Rules

1. **Never bundle festivals.** Each gets its own row, timing, and audience notation.
2. **Verify Islamic calendar dates annually** — they shift every year.
3. **Australian seasons are reversed.** Summer campaigns in AU run Dec–Feb, not Jun–Aug.
4. **India's academic year starts April** (in most states), not September.
5. **MEA has multiple overlapping school systems** — CBSE schools in UAE follow Indian calendar; MOE schools follow UAE calendar. Note which system the audience attends.
